# Anxiously Prompting

**Investigating the Role of LLMs in Supporting CS Students With Anxiety-Related Academic Difficulties**

Bachelor's thesis research code — TU Darmstadt, 2026.

## Overview

This study examines relationships between anxiety symptoms, coding-related LLM use, and AI self-efficacy among computer science students.

The quantitative analysis includes 124 complete survey records. The qualitative analysis draws on 429 retained responses from 118 respondents, manually coded using Taguette.

The primary correlation and moderation analyses did not find statistically significant evidence for the proposed relationships.

## Notebook workflow

1. `01_cleaning.ipynb` — Data cleaning and scoring.
2. `02_exploration.ipynb` — Exploratory analysis.
3. `03_quantitative_analysis.ipynb` — Correlation and moderation analyses.
4. `04_qualitative_analysis.ipynb` — Qualitative thematic analysis.
5. `05_results_tables_figures.ipynb` — Aggregate tables and figures.
6. `06_supervisor_results_summary.ipynb` — Results summary and checks.

## Requirements

Python 3.12 was used for the analysis.

Install dependencies using `python -m pip install -r requirements.txt`.

Open the notebooks using JupyterLab or VS Code with Jupyter support.

## Data availability and reproducibility

Raw survey responses, participant-level processed datasets, the Taguette database, and restricted qualitative exports are not publicly distributed.

The public version of Notebook 04 excludes participant-linked quotation attribution and verification records.

Complete execution requires authorized access to the restricted research inputs. This repository is a code and methodology archive rather than a self-contained replication package.

## Research limitations

The study uses cross-sectional, self-reported data. The findings concern associations, not causal effects.
